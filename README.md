# CW 小站

一支电键，一卷纸带。复古金属发报机风格的摩尔斯电码练习 PWA。

仓库：[AielloChan/cw-station](https://github.com/AielloChan/cw-station)。在线练习：[CW 小站](https://aiellochan.github.io/cw-station/)（GitHub Pages，无需登录）。

## 功能

- 英文练习 103 篇（100 段经典原作节选及 3 篇基础练习）、21 组模拟 CW 通联、自由发报。
- 支持按作品/作者/正文搜索、类别与长度筛选、分批列表选篇，以及避开当前篇目的随机换篇；内容全部内置，可离线选择。
- 换篇与切换模式时模拟滚筒换纸：退纸、纸头探出、停顿校正、分段送纸、压平落稳。支持连续操作、切后台收尾与减少动态效果。
- 按压真实时长决定点划，鼠标、触屏和键盘 Enter（含数字键盘）、空格均可操作；键盘长按不因按键重复而重复发报，其他控件保留自己的键盘操作。
- 逐字核对、当前字符点划提示、试听、完成进度和本轮准确率。
- 最近 30 秒滑动窗口平均发报速度，点击查看实时统计与带来源的速度手册。
- 600 Hz 发报侧音，可静音；灵敏度和字符停顿时间分别调节。
- 自由输入自动分词，支持手动插入空格与退格。
- 设置保存在浏览器；Service Worker 缓存应用、字体和内容，支持离线与安装。
- 取消触摸、切后台、失焦及 10 秒长按保护均会停音。
- 全站禁用文字选择，包括双击、长按、拖选和触摸菜单；弹窗与控件无例外。
- 手机自动使用一屏沉浸布局，纸带按剩余高度伸缩，电键和底部控件始终在屏内；短屏、横屏和安全区域分别适配。设置、码表、文章列表与速度手册使用独立弹层。
- PC 保留宽松的常规布局，可点击机身右上角「沉浸」切换；支持的浏览器同时进入原生全屏。切换保留练习进度，桌面布局偏好存于本地。手机浏览器不支持原生全屏或已在 PWA 窗口运行时，不显示多余的全屏按钮。

## 本地开发

需要 Node.js 22 或更新版本。

```sh
npm ci
npm run dev
```

开发地址 `http://localhost:5173`，开发服务器不注册 Service Worker。修改后刷新页面。

```sh
npm test
npm run build
npm start
```

生产预览地址 `http://localhost:4173`，支持完整离线缓存。

```sh
npx playwright install chromium
npm run test:browser
```

浏览器测试覆盖桌面与手机视口、触摸和键盘输入、识别错误、模式切换、设置持久化及离线重载。

## 识别规则

少于 25ms 的触碰视为抖动；默认低于 180ms 为点，否则为划。松开后连续静默 600ms 识别一个字符。自由模式静默达到字符间隔的 2.5 倍时自动插入空格。练习模式自动跨过原文空格。错误输入计入准确率分母，目标不前进。

灵敏度范围 100–300ms，字符停顿范围 300–1200ms。默认参数偏向新手；灵敏度与字符停顿设置并非 WPM。CW 文本为虚构练习情境，不是真实通联记录；连续 prosign 暂不单独识别。

纸带高亮和左侧「待输入字符」始终表示下一字。右侧在输入过程中显示正在输入的点划，识别后标明「上一字」及匹配结果。例如打完 `A LITTLE PRA` 时，下一字为 C，上一字为 A，提示为「A 已完成，请输入 C」。

## 发报速度

按最近 30 秒识别出的非空格字符计数，每 5 字符折合一词：WPM = 字符数 × 0.4。字符识别完成时入窗，满 30 秒移出，停顿包含在分母中；起步仍用完整 30 秒并标记采样进度，避免短时尖峰。每 250ms 刷新，显示一位小数，不再叠加平滑滤波。

识别出的错字计入发报量，未知编码仅计入错误尝试；正确率、正确输出速度和字符/分钟单独显示。自由模式不核对正确率。试听、自动或手动空格、删除与取消的输入不增加速度，删除也不抹去已发报的历史。换篇、切模式、重来会重置窗口，调整设置不会。

这属于实际输出速度，并非 PARIS 点划时序测得的 WPM。速度手册标明了课程目标、历史军事听抄标准、竞技发报纪录的口径及日期，链接 CWops、ARRL、美国空军与 IARU 原始资料；正文随应用离线缓存。

## 结构

| 路径 | 作用 |
| --- | --- |
| `src/morse.js` | 编码表与独立可测试的输入计时器 |
| `src/audio.js` | Web Audio 侧音与静音保护 |

| `src/paper.js` | 可中断的滚筒换纸动画 |

| `src/styles.css` | 机身、纸带、电键及响应式布局 |
| `scripts/build.mjs` | 静态构建、基于资源内容哈希生成离线缓存 |
| `public/` | 字体、许可证、图标和 manifest |

## 部署

推送到 `main` 后，GitHub Actions 自动执行单元测试、构建和桌面/手机浏览器测试，全部通过后将 `dist/` 发布到 GitHub Pages。Pull Request 只运行检查，不部署。也可手动触发工作流。

`npm run build` 生成 `dist/`。资源路径为相对路径，兼容 `/cw-station/` 子路径部署。新版本 Service Worker 会等待旧标签页关闭后激活，避免练习中突然重载；重新打开应用即可更新。

在 iOS 上用 Safari 的分享菜单「添加到主屏幕」。浏览器首次联网加载并显示「离线已就绪」后才能保证离线启动。微信内置浏览器的安装能力以实际浏览器支持为准，建议用系统浏览器打开。

## 字体与图标

Barlow Condensed 与 DM Mono 通过 Google Fonts 官方仓库取得，许可证随字体存放在 `public/fonts/`。图标为本项目原创几何图形，PNG 可用 `python3 scripts/icons.py` 重新生成（需要 Pillow）。
